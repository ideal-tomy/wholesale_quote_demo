# LP-PLAN（wholesale-quote）

LPはデモ後。操作手順は書かない。運送デモのセクション構成は使わない。

## 全体で伝えること

さっきの画面は在庫検索ではない。確認の往復を机に載せると、人の時間は返す判断に残る。確認の跡が残ると、予測や自動化の話が初めてできる。

## 主役

セクション「あとから効いてくること」。

表示: ページで唯一の全幅・濃色帯。見出しは他セクションより一段大きくする。3つの段階を横並び（スマホは縦）で見せ、3つ目だけを残像にする。スクリーンショットは置かない。ここに残る気づきが読後感になる。

## セクション

1. ヘッダー — 「デモに戻る」ボタンのみ。同じ遷移のリンクを並べない
2. ヒーロー — 在庫検索ではない、と判断の時間、を先に言う。下に静かな目次3つ
3. 時間が残るところ — デモの3手を、確認の往復が机の外に出た証拠として見せる（SS-01）
4. 人が残す仕事 — 担当者の時間の行き先を具体名で列挙。箱のカードにしない
5. あとから効いてくること（主役） — メールに閉じる → 机に残る → 次の活用
6. よくある質問 — 在庫検索か、人が要らなくなるか、予測はいつか
7. クロージング — 戻って見てほしい見方を変える
8. フッター — 注記と、同じ戻りリンク
